# E-commerce Frontend

A simple frontend for the e-commerce application that works with the backend services.

## Setup

1. Simply open the `index.html` file in your browser.

2. Make sure the backend API is running at http://localhost:8000 (or update the `API_URL` in `app.js` to point to your backend).

## Features

- Browse products
- Add products to cart
- Place orders
- View order history and details
- Real-time order status updates

## Architecture

This is a simple client-side application built with HTML, CSS, and JavaScript. It uses:

- Bootstrap for styling
- Vanilla JavaScript for functionality
- REST API communication with the backend
